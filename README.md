# Tuya Zigbee – Homey App v5 🚀
> 100+ devices, auto-resize, secrets-safe, **drivers & PR/Issue focused CI**.

## Quick Start
- **Windows**  : 
pm run dev:win
- **macOS**    : 
pm run dev:mac
- **Linux**    : 
pm run dev:linux
- **Docker**   : docker compose up
